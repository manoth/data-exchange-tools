# บันทึกการแก้ไข: เพิ่มคอลัมน์อายุในหน้าตรวจสอบสถานะการเสียชีวิต

วันที่: 2026-07-14

## สิ่งที่แก้ไข

- เพิ่มคอลัมน์ `อายุ (ปี)` ในตารางหน้าตรวจสอบสถานะการเสียชีวิต
- ตำแหน่งคอลัมน์อยู่ถัดจากคอลัมน์ `วันเกิด`
- คำนวณอายุจากวันเกิดถึงวันที่ปัจจุบันของเครื่องผู้ใช้งาน
- ถ้าวันเกิดไม่ถูกต้องหรืออ่านค่าไม่ได้ จะแสดง `-`

## ขอบเขต

- รอบนี้ทำเฉพาะการเพิ่มคอลัมน์อายุ
- การแก้ขั้นถัดมาสำหรับ `v0.1.2` เพิ่มการเรียงข้อมูลทุกคอลัมน์แล้ว
- implementation หลักอยู่ใน `static/js/death-audit.js`; ไม่ใช้ไฟล์ patch แยก
