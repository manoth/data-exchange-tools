Data Exchange Tools

คู่มือการทำงานและวิธีใช้งานระบบ

คู่มือนี้จัดทำเป็นหน้าเว็บภายในระบบ เพื่อให้ผู้ใช้งานเปิดอ่านจากหน้า Login หรือเมนู “คู่มือการใช้งาน” ได้ทันที

ข้อควรระวังด้านความปลอดภัย: คู่มือนี้ไม่แสดงรหัสผ่านจริง ไม่ควรส่งต่อรหัสผ่าน admin หรือรหัสผ่านฐานข้อมูลผ่านเอกสาร/ภาพหน้าจอ ให้ส่งแยกเฉพาะผู้มีสิทธิ์เท่านั้น

ติดตั้งและเปิดใช้งานบน Windows

  1. นำโฟลเดอร์โปรแกรมที่ build แล้วไปไว้ในเครื่อง client ของหน่วยบริการ
  2. ดับเบิลคลิก DataExchangeTools.exe เพื่อเปิด service เว็บ ระบบจะเช็ก update ล่าสุดจาก GitHub Release อัตโนมัติ
  3. ระบบจะสร้าง Windows Scheduled Task สำหรับเปิด service อัตโนมัติเมื่อ login Windows โดยไม่เปิด browser ขึ้นมาเอง
  4. ระบบจะสร้าง shortcut บน Desktop สำหรับเปิด http://localhost:8899 เมื่อต้องการเข้าใช้งาน
  5. ถ้าเปิดไม่ได้ให้ตรวจสอบว่า port 8899 ว่าง และ antivirus/firewall ไม่บล็อกโปรแกรม

เข้าใช้งานครั้งแรกและส่วนของ Admin

ลำดับบังคับสำหรับการเปิดใช้งานครั้งแรก

  1. เข้าสู่ระบบด้วยบัญชีผู้ดูแลระบบเริ่มต้น admin และรหัสผ่านเริ่มต้น admin
  2. ระบบจะพาไปหน้าเปลี่ยนรหัสผ่านผู้ดูแลระบบทันที ผู้ดูแลระบบต้องตั้งรหัสผ่านใหม่ก่อนใช้งานต่อ
  3. รหัสผ่านใหม่ต้องไม่ซ้ำกับรหัสผ่านเดิม มีอย่างน้อย 8 ตัวอักษร และมีตัวพิมพ์เล็ก ตัวพิมพ์ใหญ่ ตัวเลข และอักขระพิเศษ
  4. เมื่อเปลี่ยนรหัสผ่านสำเร็จ ระบบจะบังคับให้ตั้งค่าการเชื่อมต่อฐานข้อมูล HIS/HosXP ของหน่วยบริการ
  5. ต้องกด “ทดสอบการเชื่อมต่อ” ให้สำเร็จก่อน จึงจะบันทึกการตั้งค่าและเริ่มใช้งานระบบได้

การตั้งค่าฐานข้อมูลครั้งแรก

เมื่อมาถึงหน้าตั้งค่าฐานข้อมูล ให้กรอก Host, Port, Database, Username และ Password ของฐานข้อมูล HIS/HosXP ของหน่วยบริการ จากนั้นต้องกด “ทดสอบการเชื่อมต่อ” ก่อนบันทึกทุกครั้ง

บัญชี admin ใช้ทำอะไร

admin ใช้สำหรับตั้งค่าฐานข้อมูล ตรวจ update ปิด service และจัดการส่วนที่ผู้ใช้ทั่วไปไม่ควรเข้าถึง

หลังตั้งค่าครั้งแรก

เมื่อฐานข้อมูลเชื่อมต่อสำเร็จ ผู้ใช้ทั่วไปจะ Login ด้วยบัญชีจากตาราง opduser ของ HosXP ได้

ถ้ายังไม่ทดสอบการเชื่อมต่อ หรือทดสอบไม่สำเร็จ ระบบจะไม่ให้บันทึกการตั้งค่า เพื่อป้องกันการใช้งานด้วย config ที่ผิด และถ้ามีการแก้ไขค่าใดหลังทดสอบผ่าน ต้องทดสอบใหม่ก่อนบันทึกอีกครั้ง

การใช้งานโปรแกรมแบบปกติ

ขั้นตอนอัปโหลดและแปลงข้อมูล

  1. เข้าเมนู “อัปโหลด & แปลงข้อมูล”
  2. เลือกไฟล์ Exchange นามสกุล .xlsx ที่ดาวน์โหลดจาก HDC
  3. ตรวจสอบตัวอย่างข้อมูล 5 แถวแรก
  4. เลือกหน่วยบริการจาก HOSCODE/HOSNAME หรือเลือก “ทั้งหมด”
  5. กด “แปลงข้อมูล” ระบบจะนำ PID และ HOSCODE ไปตรวจร่วมกับฐานข้อมูล HIS
  6. ตรวจผลลัพธ์ในตาราง กรอง/ค้นหาได้ และกด “ส่งออก Excel” เมื่อต้องการไฟล์ผลลัพธ์

ประวัติการแปลงและการกลับมาดูรายละเอียด

เมนูประวัติช่วยให้กลับมาดาวน์โหลดไฟล์ที่เคยแปลงสำเร็จ หรือกด “ดูรายละเอียด” เพื่อเปิดตารางผลลัพธ์เดิมกลับมาค้นหา/กรองซ้ำได้

Update โปรแกรม

  1. เมื่อ service เริ่มทำงาน ระบบจะเช็ก update จาก GitHub Release ให้อัตโนมัติหนึ่งครั้ง
  2. ถ้าเป็น Windows .exe update ระบบจะดาวน์โหลด ตรวจ SHA256 แทนที่ไฟล์ .exe และ restart service เพื่อใช้เวอร์ชันใหม่
  3. ถ้าเป็น frontend update ระบบจะดาวน์โหลด ตรวจ SHA256 และติดตั้งลงโฟลเดอร์ static ให้อัตโนมัติ
  4. ผู้ดูแลระบบยังสามารถเข้าสู่ระบบด้วย admin ไปที่เมนู “ตั้งค่า” แล้วกด “เช็ก Update” เพื่อตรวจซ้ำได้
  5. ถ้ามีเวอร์ชันใหม่ที่ต้อง update ด้วยมือ ระบบจะแสดงปุ่มให้กด Update
  6. เมื่อ update เฉพาะ frontend สำเร็จ ให้ refresh browser หนึ่งครั้ง

แก้ปัญหาเบื้องต้น

Login ไม่ได้

ตรวจสอบว่าตั้งค่าฐานข้อมูลสำเร็จแล้ว และบัญชีผู้ใช้มีอยู่ในตาราง opduser ของ HosXP

แปลงแล้วจับคู่ไม่ได้

ตรวจสอบว่า Excel มี column HOSCODE และ PID ถูกต้อง โดยระบบจะตรวจ HOSCODE กับ opdconfig.hospitalcode และตรวจ PID กับ person.person_id

Update ไม่ขึ้น

ตรวจสอบ internet ของเครื่อง client, GitHub Release ล่าสุดต้องมี latest.json และไฟล์ update ต้องมีค่า SHA256 ตรงกับ manifest
